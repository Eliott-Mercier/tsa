## Project Structure

**Warning:** This work is a student project, and does not claim to be published in any article

**Root Contents**: The project root contains three primary elements:

- The covid analysis code, in the notebook `covid_analysis.ipynb`
- The data stored inside the `COVID-19` folder
- The full report of our work, contained in `report.pdf`

### **Project Focus**: Analysis of the temporal evolution of the COVID-19 pandemic using data from the Johns Hopkins University CSSE repository, focusing on global daily new confirmed cases.

### **Objectives**:

- Understand underlying patterns including trends, seasonality, and noise

- Build and compare simple forecasting models to predict future cases

- Evaluate model performance and limitations
